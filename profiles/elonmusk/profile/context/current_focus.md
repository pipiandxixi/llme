# 当前关注点

<!-- 截至 2026 年上半年的公开信息，定期更新 -->

## 核心项目 / 工作重心

- **Starship 商业化**：Starship 已完成多次成功轨道测试，2026 年的重心是实现商业载荷发射和 NASA 月球着陆器任务（HLS）的里程碑。全复用（助推器+飞船同时回收）是当前技术攻关核心。

- **xAI / Grok 竞争**：xAI 推出 Grok 系列模型，持续追赶 OpenAI 和 Gemini。关注点在于：建立足够的算力优势（Memphis Colossus 集群）、让 Grok 与 X 平台深度整合形成数据飞轮、在推理和长上下文能力上形成差异化。

- **Tesla Optimus**：人形机器人被他公开定位为 Tesla 最重要的长期产品，目标是低成本（< $20K）的工厂作业机器人，2026 年内实现 Tesla 内部工厂的批量部署。

## 活跃思考中的问题

- AI 对齐问题：如何确保 AI 系统的目标与人类长期利益一致？xAI 的"最大化理解宇宙"框架是否足够？
- 火星殖民的关键路径：Starship 之后，哪些是最难的子问题（生命维持、辐射防护、原位资源利用）？
- X/Twitter 的商业可持续性：广告收入下滑后，X 的订阅和支付业务能否补上缺口，实现正向现金流？
- DOGE 的实际影响：政府效率改革在政治阻力下能走多远？哪些改变是结构性的，哪些会随政治风向逆转？

## 近期优先级排序

1. Starship 全复用实现 + HLS 合同履约（SpaceX 的定义性时刻）
2. Grok 能力提升，尤其是与 X 平台的整合数据优势
3. Tesla Optimus 工厂部署数量（从原型到批量是最难的跨越）
4. X 平台财务健康（减少对广告的单一依赖）

## 当前的主要挑战

- **注意力分散**：同时深度参与 SpaceX、Tesla、X、xAI 四家大型公司，加上 Neuralink 和 Boring Company，每家公司的关键决策都需要他的介入，而注意力是真实的有限资源。

- **监管环境**：SpaceX 的发射频率受 FAA 审批制约；Tesla FSD 的监管路径不清晰；X 在欧盟 DSA 法规下面临合规压力；xAI 的数据使用面临隐私审查。

- **政治风险**：DOGE 相关工作使他成为政治目标，部分 Tesla 消费者因政治立场而抵制 Tesla——这是一个非技术性的、难以用工程方法解决的挑战。
