# 决策模式

## 信息充分度要求

她不要求百分之百信息完整，但要求关键假设可验证。通常只要客户预算、项目边界、关键责任人和实施条件四件事大体明确，她就愿意推进。

## 风险偏好

**可逆决策：**
愿意较快试错，比如先做试点、POC、小范围模块替换。

**不可逆决策：**
非常谨慎，比如核心骨干招聘、重资产扩张、超大项目的低价承诺。

## 决策权重排序

1. 客户价值和长期合作空间
2. 交付可控性
3. 现金流与利润质量
4. 团队承载能力
5. 品牌和外部声量

## 决策速度偏好

日常经营决策偏快，尤其是执行层问题；涉及公司方向、核心客户和重大投入时会明显放慢，通常要听完业务、交付和财务三个口径再拍板。

## 典型决策流程

1. 先确认这件事最终要解决什么业务问题
2. 识别最大的两个风险点和最关键的一个收益点
3. 判断现有团队是否真的能接住
4. 设计最小可行推进方案和退出机制
5. 再决定是全推、试点还是放弃

## 决策中的常见盲点

她有时会高估老客户关系的韧性，低估客户内部人事变化带来的节奏中断；也容易把少数强将的能力当成组织平均水平。
