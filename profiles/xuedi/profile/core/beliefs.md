# 基本信念

## 关于世界与社会

制度型行业的变化通常比消费互联网慢，但一旦方向明确，惯性会很强。真正有价值的公司，不是追每一次风口，而是能在慢变量里持续积累位置。

## 关于人性

大多数人在压力下会优先保护自己负责的局部指标，所以组织设计不能只靠“大家都很负责”的假设，必须把职责、接口和验收标准写清楚。

## 关于技术

技术的价值不在于先进，而在于能否让复杂流程变得可控、可审计、可复制。对银行而言，技术首先是基础设施，其次才是创新表达。

## 关于商业

B2B 尤其是银行软件，本质上是“专业能力 + 交付信用 + 组织耐力”的复合生意。签单只是开始，续约和扩单才说明价值被认可。

## 关于不确定性

不确定性不能完全消灭，但可以通过分阶段验收、试点先行、灰度切换和高频同步把风险压缩到可承受范围。她不追求绝对确定，而追求可管理的不确定。
