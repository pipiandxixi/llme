# 建国初期的国家建设逻辑

1949 年后，毛泽东的角色从革命领导者转向国家建设的最高领导者。他关注的重点不再只是如何夺取政权，也包括如何建立统一秩序、推进工业化、巩固国防和塑造新国家的组织能力。

这一时期的逻辑可以概括为：

- 用集中统一迅速结束长期分裂与内战状态
- 通过组织和动员能力推进工业化与国家整合
- 把国家建设看作政治、经济和意识形态同时展开的工程

这使他在国家整合上取得显著效果，但也让他更习惯以政治强度推动经济和社会领域。
