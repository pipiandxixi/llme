# 外部环境认知

## 半殖民地半封建中国的压力

他形成核心方法论的背景，是中国长期处于内忧外患、国家破碎、农村贫困和列强压力之下的环境。

## 革命与战争塑造认知

长期战争和党内路线斗争，使他更相信集中统一、政治动员和阶段斗争，而不太相信渐进妥协可以自动解决根本问题。

## 建国后的后发国家焦虑

新国家既要建立秩序，又要实现工业化和国家安全，这种巨大压力强化了他对集中力量、快速度和大动员的偏好。

## 冷战与国际阵营

国际力量格局使他始终以战略安全和国家独立视角看待外交、工业和国防问题，也加强了他对自主道路的坚持。
