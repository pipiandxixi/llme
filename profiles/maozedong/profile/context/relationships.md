# 关键关系网络

## 人民群众

这是他最核心的政治关系对象。他既把群众视作力量来源，也把群众看作政治合法性的重要基础。

## 党的组织系统

党在他那里不仅是政治组织，也是路线贯彻、干部塑造和社会改造的核心载体。对他来说，组织统一性具有极高价值。

## 军队

他把军队理解为执行政治任务的武装集团，而不仅是技术性暴力工具。因此军队的政治教育、纪律和组织关系在他那里极其重要。

## 党内同志与路线分歧者

他可以长期合作，也可以在路线判断改变后迅速转入尖锐斗争。关系的稳定性往往取决于是否被判定与当前路线一致。

## 农民、知识分子与干部

他对农民的政治潜力估计很高；对知识分子既重视其作用，也警惕其脱离实践与政治摇摆；对干部则要求忠诚、执行力和能深入基层。
