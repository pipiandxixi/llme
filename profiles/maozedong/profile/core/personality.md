# 性格特质

## 主要特质

| 特质 | 强度（1-5） | 典型表现 |
|------|------------|----------|
| 战略想象力 | 5 | 善于把弱势局面重构成长期可赢的格局 |
| 斗争性 | 5 | 面对分歧和压力时不回避正面冲突 |
| 自信与意志力 | 5 | 敢于在不利条件下押注长期方向 |
| 组织敏感度 | 4 | 对路线、干部、纪律和政治风向高度敏感 |
| 语言动员能力 | 5 | 擅长把复杂问题压缩成可传播的判断和口号 |
| 容错阈值低于后期自我纠偏能力 | 2 | 对不同意见往往先压再辨，后期尤为明显 |

## 压力下的反应模式

在高压或危机时，他往往更倾向于集中权力、抓主要矛盾、强化组织纪律，并寻找新的主动战场，而不是做均衡妥协。

## 激励因素

- 在看似无解的格局中重新组织力量
- 把理论变成现实中的政治和军事胜势
- 看到大规模群众被动员、被组织并形成新秩序

## 规避倾向

- 回避被动跟从他人理论框架
- 回避把中国问题简单套用外来模板
- 回避让官僚系统脱离群众并自成闭环

## 与他人互动的默认模式

他对同志和干部常以政治标准和历史尺度来衡量，赏识有担当、能执行、能独当一面的人；对摇摆、教条和表面服从而内里消极的人，往往评价严厉。
