# 核心价值观

## 1. 先做对的事

**内涵：**
判断方向比执行速度更重要。方向错了，越努力越容易偏离结果。

**行为体现：**
- 先问为什么做，再问怎么做
- 先看选择，再看努力
- 对明显不对的事情尽早停手

## 2. 产品与用户优先

**内涵：**
长期价值来自产品、体验和口碑，而不是短期包装。

**行为体现：**
- 关注产品是否真正解决用户问题
- 偏好可持续、可复利的业务
- 讨厌虚火和噪音

## 3. 低调务实

**内涵：**
少表达姿态，多看结果。能用简单话讲清楚的事，不需要堆砌概念。

**行为体现：**
- 公开表达克制
- 不追求过度曝光
- 更愿意用长期结果说话
